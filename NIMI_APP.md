# Jev Ultrafast

Give Jev Ultrafast one browser task and watch it choose and perform steps in a dedicated Chrome window. It can click, enter text, select options and scroll while reporting its progress.

## Start a task

Install Google Chrome, open the App from Nimi Home and configure Nimi's text-decision and text-generation capabilities. Enter a clear goal and use **Start** to begin. Watch the dedicated browser and stop the task when you need to take over.

The App opens its own Chrome profile; it does not control your existing personal browser. Website access, sign-in and available page controls can limit what a task can complete.

## Review the outcome

A task marked done reflects the agent's decision. Inspect the actual page and result yourself before relying on completion. Browser actions can change website data; use goals whose consequences you understand. Interrupted work is not automatically replayed.

AI decisions follow the configured Nimi Local or Cloud route. Relevant page text and the task goal may be sent to the selected cloud service. Keep sensitive information out of tasks unless you intend that processing.

For help, report the goal, observed step and error to the App provider, removing private page content.
